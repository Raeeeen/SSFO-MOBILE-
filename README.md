📲 SSFO Mobile – Face Recognition DTR System (Mobile App)

📱 Overview

SSFO Mobile is the mobile application companion to the SSFO web-based system.
It enables users to register their face and use facial recognition for a digital Daily Time Record (DTR) system — allowing seamless and contactless check-in and check-out for attendance.

✨ Features

-- 👤 Face Registration
Scan and save a user’s face for future attendance verification.

-- 🕒 Face-Based DTR Logging
Automatically mark attendance (in/out) by scanning the registered face.

-- 🔄 Integration with SSFO Web Dashboard
Attendance data captured via the mobile app is synced to the SSFO web system for real-time monitoring.

-- 📱 Built for Android using native development tools.

🛠️ Technologies Used

-- Android Studio

-- Java / Kotlin

-- Camera API for face capture

-- ML Kit

-- Firebase (Authentication / Realtime Database)

🔗 Related Project

👉 SSFO Web Dashboard – Web-based interface for managing and viewing DTR records.
